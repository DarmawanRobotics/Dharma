\section{Evaluation}
\label{sec:eval}

\textbf{Simulation protocol.} The simulator moves an omnidirectional or differential body with
the acceleration limits of the profile, integrates the measured time step and detects
collisions. Its LiDAR model follows the Mid-360 (vertical field of view from $-7^\circ$ to
$52^\circ$ at the mount height, minimum and maximum range, noise, dropout windows). Odometry
drifts as $\T{odom}{base} \leftarrow \T{odom}{base} \exp(\vect{\xi})$ with $\vect{\xi} \sim
\mathcal{N}(\vect{0}, \boldsymbol{\Sigma}\,\Delta s)$, plus a yaw bias, a scale error and slip;
LiDAR and odometry stamps lag by a latency $L$ and commands pass through a delay queue. Every
scenario (world, timed obstacles, dropouts, latencies) is a YAML file with a seed, so each run
is reproducible in CI. \todo{scenario list, number of seeds and runs per condition}
